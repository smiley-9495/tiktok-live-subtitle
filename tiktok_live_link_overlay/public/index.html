중요 안내

음성 인식은 브라우저의 Web Speech 기능을 사용합니다. Chrome/Edge 지원 여부와 인터넷 상태에 따라 달라질 수 있습니다. 번역은 무료 공개 MyMemory API를 사용하므로 사용량 제한, 지연 또는 장애가 발생할 수 있습니다. 사이트 운영자는 마이크 오디오를 자체 서버로 전송하지 않지만 브라우저 음성 인식 엔진의 처리 정책은 해당 브라우저 제공자에 따릅니다.

이 웹사이트는 별도의 Python 서버 없이 정적 호스팅에서 동작하도록 제작되었습니다. 방문자별 자막과 설정은 각 브라우저 안에서 분리됩니다. 무료 번역 API는 무제한/상업적 서비스가 보장되지 않습니다.
